# Roadmap — Divine Motion V2

- **Phase 0 — Gouvernance** : terminée.
- **Phase 1 — Stratégie produit & UX** : finalisée le 15 septembre 2026 avec le changement structurant Travail curaté (remplace Projects), direction Dark Editorial, typographie proposée, CMS mis à jour. Voir `PRODUCT_REQUIREMENTS.md`, `UX_FLOWS.md`, `INFORMATION_ARCHITECTURE.md`.
- **Phase 2 — Design System** : direction validée (Dark Editorial, palette, grille, typographie proposée). Reste à figer avant Phase 3 : combinaison typographique définitive (Instrument Serif + Manrope encore challengeable), maquettes complètes des 5 pages + Confidentialité. Voir `DESIGN_SYSTEM.md`.
- **Phase 3 — Site public (données mockées)** : prochaine étape. À construire contre le modèle Travail curaté, pas contre un modèle Projects. Nécessite un Implementation Brief dédié avant tout code.
- **Phase 4 — Architecture Data** : modèle de données complet conçu (Brief 009, voir `DATA_ARCHITECTURE.md` et `docs/drafts/001_initial.sql`) — schéma en attente de validation avant toute migration D1 réelle. Garde-fou de publication résolu (ADR-011). Reste ouvert : choix Cloudflare Images vs Image Resizing (voir `TECHNICAL_ARCHITECTURE.md`, ADR-005).
- **Phases 5-10** : inchangées dans leur séquencement (CMS, contenu réel, QA, staging final, production, maintenance), mais leur contenu concret est mis à jour partout où elles référençaient « Projects » (remplacé par Travail curaté).
